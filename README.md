## 📚 Contenidos Abordados

En esta práctica se aplicaron los estándares semánticos fundamentales de HTML5:

1. **Estructura básica de un documento HTML:**
   - `<!DOCTYPE html>`: Declaración del tipo de documento HTML5.
   - `<html>`: Elemento raíz del documento web.
   - `<head>`: Contenedor de metadatos, título (`<title>`) y estilos asociados a la página.
   - `<body>`: Cuerpo principal visible que contiene todo el contenido renderizado para el usuario.

2. **Jerarquía de títulos y encabezados:**
   - `<h1>`: Título principal del documento (Nombre del desarrollador/estudiante).
   - `<h2>`: Subencabezados para estructurar secciones temáticas (Presentación, Experiencia, Habilidades, Intereses, Enlaces).
   - `<h3>`: Subsecciones específicas dentro de cada categoría.

3. **Elementos de texto y agrupación:**
   - `<p>`: Párrafos de texto descriptivo y de presentación profesional.
   - `<strong>` y `<em>`: Énfasis e importancia textual.

4. **Listas ordenadas y no ordenadas:**
   - `<ul>`: Lista desordenada para agrupar elementos relacionados.
   - `<li>`: Cada uno de los elementos dentro de la lista (habilidades técnicas, habilidades blandas, experiencia e intereses).

5. **Elementos multimedia e hipervínculos:**
   - `<img>`: Inserción de imágenes con atributos accesibles como `alt`, `width` y `height`.
   - `<a>`: Enlaces o hipervínculos hacia sitios externos y redes (con atributos seguros `target="_blank"` y `rel="noopener noreferrer"`).
